# GitHub math color — copy-paste examples

Every block below was generated by `scripts/comment.js` (the renderer the action uses), so it is exactly what a
posted comment contains. Paste the **Source** block into a pull-request or issue comment and use **Preview**.
Read the companion guide first: [`docs/github-math-color-guide.md`](../docs/github-math-color-guide.md) — it lists what does
*not* work and why, and how to troubleshoot.

> Two rules that trip everyone: (1) test on a page with no other math — GitHub's budget of ~145 expressions is
> per page, so a page full of earlier probes renders nothing new; (2) in comments a plain newline is a line break,
> so do **not** add `<br>` (it doubles the gap). This file adds `<br>` only for its own rendered previews, because
> `.md` files treat newlines as spaces.

### 1. Minimal sanity check

Three colored glyphs with hex colors. If this does not render, nothing else will — check the page budget.

**Source — paste into a PR or issue comment:**

````markdown

````
